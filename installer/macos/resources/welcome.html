DisplayXR Leia SR Plug-in @VERSION@

The Leia SR display processor for the DisplayXR OpenXR runtime: it weaves DisplayXR content for Leia SR 3D displays with the LeiaSR Metal weaver.

  • Installs DisplayXR-LeiaSR.dylib to /Library/Application Support/DisplayXR/lib/displayxr/plugins/ and its discovery manifest 050-leia-sr.json to /Library/Application Support/DisplayXR/DisplayProcessors/.
  • Can be installed before or after the DisplayXR runtime and the LeiaSR platform. Without the LeiaSR platform the plug-in loads and reports the platform as absent; the runtime then uses its simulated display.
  • If a DisplayXR runtime older than @MIN_RUNTIME_VERSION_TEXT@ is installed, the installer stops and asks you to update the runtime first.
  • A running DisplayXR service is restarted so it picks up the plug-in.

To uninstall:
sudo "/Library/Application Support/DisplayXR/LeiaSR/uninstall.sh"
